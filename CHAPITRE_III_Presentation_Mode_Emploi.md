# CHAPITRE III : PRÉSENTATION DU PROJET ET MODE D'EMPLOI

---

## III.1 Présentation générale du projet CropGPT

Le projet **CropGPT** (anciennement « Second Cerveau Agricole Malgache ») est une plateforme numérique intelligente dédiée à l'agriculture à Madagascar. Son objectif principal est de démocratiser l'accès aux connaissances agricoles en utilisant les avancées de l'intelligence artificielle.

Le nom « CropGPT » signifie « Assistant agricole intelligent » (Crop = culture en anglais, GPT = Generative Pre-trained Transformer). Ce nom reflète la mission du projet : fournir un assistant virtuel capable de répondre aux questions agricoles complexes en utilisant le langage naturel.

### Mission

Notre mission est simple mais ambitieuse : réduire la fracture informationnelle dans le secteur agricole malgache en rendant les connaissances accessibles à tous, du paysan analphabète au chercheur qualifié.

### Vision

Nous envision un Madagascar où chaque agriculteur dispose des outils nécessaires pour prendre des décisions éclairées, optimiser ses rendements et contribuer à la sécurité alimentaire nationale.

---

## III.2 Objectifs du projet

Le projet poursuit plusieurs objectifs complémentaires :

### Objectif 1 : Centraliser les connaissances

Regrouper dans une base de données unique toutes les informations pertinentes sur l'agriculture malgache : variétés, méthodes, maladies, sols, clima. Cette centralisation facilite l'accès et garantit la cohérence des informations.

### Objectif 2 : Faciliter l'apprentissage

Proposer des formations gratuites pour initier les utilisateurs aux outils numériques. Chaque paysan ayant un smartphone peut apprendre à utiliser l'application en quelques minutes.

### Objectif 3 : Améliorer les rendements

Fournir des recommandations personnalisées basées sur la localisation, le type de sol et la culture souhaitée. Ces recommandations permettent d'optimiser les intrants et d'augmenter les rendements.

### Objectif 4 : Diagnostiquer les maladies

Permettre un diagnostic rapide des maladies des cultures grâce à l'IA. Plus besoin d'attendre un expert pour identifier un problème.

### Objectif 5 : Prédire les rendements

Estimer les rendements potentiels en fonction des conditions climatiques et historiques. Cette fonctionnalité aide à la planification.

## III.3 Fonctionnalités principales

L'application CropGPT propose plusieurs fonctionnalités clés :

### A) Assistant conversationnel intelligent

L'utilisateur peut dialoguer avec l'IA en posant des questions en langage naturel. Par exemple :
- « Comment planter le riz dans la région Analamanga ? »
- « Quelles sont les maladies du manioc ? »
- « Quand semer le maïs ? »

Le système analyse la question, recherche dans la base de connaissances et fournit une réponse contextualisée. L'utilisateur peut également sélectionner un mode « Paysan » (langage simplifié) ou « Expert » (terminologie technique).

### B) Carte interactive de Madagascar

La carte affiche les 22 régions de Madagascar avec leurs statistiques agricoles. En cliquant sur une région, l'utilisateur obtient :
- Les cultures principales
- Les moyennes de rendement
- Les données météorologiques
- Les zones climatiques

Cette visualisation aide à comprendre le contexte régional.

### C) Module de prédiction

En entrant sa localisation et sa culture, l'utilisateur obtient une estimation de rendement basée sur :
- Les données historiques de la région
- Les prévisions météorologiques (via Open-Meteo)
- Les caractéristiques du sol

### D) Diagnostic des maladies

L'utilisateur décrit les symptômes observés sur sa plante. Le système propose un diagnostic probabiliste avec :
- La maladie la plus probable
- Les traitements recommandés
- Les produits disponibles à Madagascar

### E) Suggestions de plantation

Le système propose des suggestions personnalisées basées sur :
- La région et l'altitude
- Le type de sol
- La saison
- Les préférences de l'utilisateur

## III.4 Interface utilisateur

L'interface de CropGPT a été conçue pour être simple et intuitive, même pour les utilisateurs peu familiers avec le numérique.

### Page d'accueil

La page d'accueil présente trois éléments principaux :
1. Le bouton « Commencer » pour lancer une conversation
2. Les suggestions de questions fréquentes
3. Un globe 3D interactif montrant Madagascar

Le design utilise des effets visuels modernes :
- Particules animées en arrière-plan (mode sombre : cyan, mode clair : vert émeraude)
- Typographie claire avec la police « Outfit »
- Couleurs vertes et cyan reprenant le thème agricole et technologique

### Sidebar de navigation

La barre latérale permet de naviguer entre les sections :
- **Dashboard** : Vue d'ensemble avec statistiques
- **Chat** : Assistant conversationnel
- **Prévisions** : Module de prédiction
- **Paramètres** : Configuration du compte

La sidebar est repliable pour maximiser l'espace de visionnage sur mobile.

### Zone de conversation

La zone de conversation affiche :
- Les messages de l'utilisateur (bulle verte)
- Les réponses de l'IA (bulle transparente)
- Les sources utilisées (badges cliquables)
- Le score de confiance RAG

### Mode sombre/clair

L'application supporte les deux modes :
- **Mode sombre** : Fond noir (#030712), particules cyan
- **Mode clair** : Fond blanc (#F8FAFC), particules vert émeraude

Le toggle se trouve dans la sidebar, au-dessus du nom d'utilisateur.

## III.5 Comment utiliser l'application au quotidien

### Pour un paysan : Poser une question simple

1. Ouvrir l'application
2. Cliquer sur « Commencer »
3. Poser sa question oralement ou par écrit
4. Lire (ou écouter) la réponse
5. Suivre les recommandations

Exemple : « Je souhaite cultiver du riz à Antsirabe, quelles sont les étapes ? »

### Pour un biotechnicien : Faire un diagnostic

1. Cliquer sur l'onglet « Diagnostic »
2. Décrire les symptômes observés
3. Indiquer la localisation
4. Consulter le diagnostic proposé
5. Suivre le traitement recommandé

### Pour un étudiant : Rechercher des informations

1. Utiliser la barre de recherche
2. Filtrer par région ou culture
3. Consulter les sources scientifiques
4. Exporter les données pour le mémoire

## III.6 Formations gratuites

Nous proposons plusieurs formations pour initier les utilisateurs :

### Formation 1 : Initiation au smartphone agricole (30 min)

- Utilisation de base du smartphone
- Navigation dans l'application
- Poser une question à l'IA

### Formation 2 : Diagnostic des maladies (45 min)

- Observer les symptômes
- Utiliser l'interface de diagnostiquer
- Interpréter les résultats

### Formation 3 : Optimisation des rendements (1h)

- Utiliser le module de prédiction
- Analyser les recommandations
- Ajuster les pratiques culturales

Ces formations sont disponibles :
- En présentiel dans les centres FOFIFA
- En ligne via l'application
- En format vidéo sur YouTube

## III.7 Accessibilité

L'application est conçue pour être accessible au plus grand nombre :

**Sur smartphone** : L'application fonctionne hors ligne pour les fonctionnalités de base. Aucune connexion n'est requise pour consulter les informations en cache.

**Sur ordinateur** : Version web optimisée pour les ordinateurs modestes (processeurs Intel Celeron, 4Go de RAM).

**Pour les personnes en situation de handicap** : L'interface respecte les normes WAI-ARIA. Les lecteurs d'écran sont compatibles.

**Dans les zones rurales** : L'application utilise un format compressé pour minimiser la consommation de données (estimée à 5MB par session).
